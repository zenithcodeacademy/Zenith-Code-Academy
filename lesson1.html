FREE LESSON 01

Variable

Programming မှာ Data တွေကို ဘယ်လိုသိမ်းပြီး အသုံးပြုမလဲ?

🎯 Learning Objective

ဒီ Lesson ပြီးဆုံးတဲ့အခါ Variable ဆိုတာဘာလဲ၊ Variable ကို ဘာကြောင့်အသုံးပြုရသလဲ၊ Data တွေကို Variable ထဲမှာ ဘယ်လိုသိမ်းဆည်းအသုံးပြုရသလဲ ဆိုတာကို နားလည်လာမှာဖြစ်ပါတယ်။

1. Variable ဆိုတာဘာလဲ?

Programming မှာ Variable ဆိုတာ Data တစ်ခုကို သိမ်းဆည်းထားနိုင်တဲ့ နာမည်ပေးထားတဲ့နေရာတစ်ခု လို့ ရိုးရိုးရှင်းရှင်းနားလည်နိုင်ပါတယ်။

Real-life Example 💡

သင့်အိမ်မှာ ပစ္စည်းတွေကို သိမ်းဖို့ Box တွေကို နာမည်တပ်ထားတယ်လို့ စဉ်းစားကြည့်ပါ။

Box → Name: Books
အဲဒီ Box ထဲမှာ စာအုပ်တွေ ထည့်ထားနိုင်ပါတယ်။

Programming မှာလည်း ဒီလိုပါပဲ။ Variable က Data ကို သိမ်းထားတဲ့ Box တစ်ခုလို အလုပ်လုပ်ပါတယ်။

2. Variable ကို ဘာကြောင့်သုံးတာလဲ?

Program တစ်ခုရေးတဲ့အခါ Data တွေကို နောက်ပိုင်းမှာ ပြန်အသုံးပြုဖို့ လိုအပ်တတ်ပါတယ်။ အဲဒီအတွက် Data တွေကို Variable ထဲမှာ သိမ်းထားနိုင်ပါတယ်။

ဥပမာ — Student တစ်ယောက်ရဲ့ အသက်ကို သိမ်းထားမယ်ဆိုပါစို့။

age = 20

ဒီမှာ age က Variable Name ဖြစ်ပြီး 20 က သိမ်းထားတဲ့ Value ဖြစ်ပါတယ်။

3. Variable ရဲ့ Basic Structure

Variable ကို နားလည်ဖို့ အဓိကအချက်က Name နဲ့ Value ပါ။ 

age = 20
age → Variable Name
20 → Value

4. Programming Example

Python မှာ Variable တစ်ခုဖန်တီးဖို့ Variable Name နဲ့ Value ကို = နဲ့ သတ်မှတ်နိုင်ပါတယ်။ 

name = "Zenith Code Academy"
age = 20

print(name)
print(age)

Output

Zenith Code Academy
20

ဒီမှာ name Variable ထဲမှာ "Zenith Code Academy" ကို သိမ်းထားပြီး age Variable ထဲမှာ 20 ကို သိမ်းထားပါတယ်။

5. Variable ကို ပြန်အသုံးပြုခြင်း

Variable ရဲ့ အရေးကြီးတဲ့ အားသာချက်တစ်ခုက သိမ်းထားတဲ့ Data ကို နောက်ပိုင်းမှာ ပြန်အသုံးပြုနိုင်တာပါ။ 

score = 80

print(score)
print(score + 10)

Output

80
90

score ထဲမှာ 80 ကို သိမ်းထားပြီး အဲဒီ Variable ကို ပြန်အသုံးပြုပြီး 10 ထပ်ပေါင်းထားတာကို တွေ့ရပါတယ်။

📌 Key Points

  • Variable သည် Data ကို သိမ်းဆည်းအသုံးပြုရန် နာမည်ပေးထားသောနေရာတစ်ခု ဖြစ်သည်။
  • Variable တစ်ခုမှာ အဓိကအားဖြင့် Name နဲ့ Value ရှိသည်။
  • Variable ထဲမှာ သိမ်းထားတဲ့ Data ကို နောက်ပိုင်းမှာ ပြန်အသုံးပြုနိုင်သည်။
  • Programming Language တစ်ခုနဲ့တစ်ခု Variable ရေးသားပုံ ကွာနိုင်သည်။
