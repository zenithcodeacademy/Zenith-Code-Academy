FREE LESSON 01

What is Programming?

Computer ကို အလုပ်လုပ်စေဖို့ ဘယ်လိုညွှန်ကြားချက်တွေ ပေးရမလဲ?

🎯 Learning Objective

ဒီ Lesson ပြီးဆုံးတဲ့အခါ Programming ဆိုတာဘာလဲ၊ Computer က ဘာကြောင့် Instructions လိုအပ်သလဲ၊ Programming Language ဆိုတာဘာလဲဆိုတာကို အခြေခံအနေနဲ့ နားလည်လာမှာဖြစ်ပါတယ်။

1. Programming ဆိုတာဘာလဲ?

Programming ဆိုတာ Computer ကို ဘာလုပ်ရမလဲဆိုတာ Instructions တွေ ရေးသားပြီး ညွှန်ကြားပေးတဲ့ လုပ်ငန်းစဉ်တစ်ခု ဖြစ်ပါတယ်။

ရိုးရိုးရှင်းရှင်းပြောရရင် 💡

Computer က ကိုယ်တိုင်ဘာလုပ်ရမလဲ ဆုံးဖြတ်နိုင်တဲ့အရာ မဟုတ်ပါဘူး။

ကျွန်တော်တို့က ဘာလုပ်ရမလဲ၊ ဘယ်လိုလုပ်ရမလဲ ဆိုတာကို Instructions အဆင့်ဆင့်နဲ့ ပြောပြပေးရပါတယ်။

အဲဒီ Instructions တွေကို Programming Language အသုံးပြုပြီး ရေးသားတာကို Programming လို့ခေါ်ပါတယ်။

2. Computer က ဘာကြောင့် Instructions လိုတာလဲ?

Computer ဟာ လူတစ်ယောက်လို မိမိဘာသာ ရည်ရွယ်ချက်နဲ့ ဆုံးဖြတ်ပြီး အလုပ်လုပ်တာမဟုတ်ပါဘူး။

ကျွန်တော်တို့ ပေးတဲ့ Instructions တွေအတိုင်း လုပ်ဆောင်ပါတယ်။

ဥပမာ —

Calculator တစ်ခုမှာ 10 + 20 ကို တွက်ခိုင်းမယ်ဆိုရင် Computer ကို ဘာတွေ လုပ်ရမလဲဆိုတာ အဆင့်ဆင့် ညွှန်ကြားပေးရပါတယ်။

3. Programming Language ဆိုတာဘာလဲ?

Computer ကို Instructions ပေးဖို့ လူတွေ နားလည်ရေးသားနိုင်ပြီး Computer ကလည်း နားလည်လုပ်ဆောင်နိုင်တဲ့ စည်းမျဉ်းများပါဝင်တဲ့ Language တွေကို Programming Language လို့ခေါ်ပါတယ်။

လူတွေမှာ English၊ Myanmar စတဲ့ ဘာသာစကားတွေရှိသလို Computer Program ရေးတဲ့အခါမှာလည်း Programming Languages တွေ အသုံးပြုပါတယ်။

ဥပမာ — Python, Java, C, C++, JavaScript

4. Simple Programming Example

Python ကို အသုံးပြုပြီး Computer ကို စာတစ်ကြောင်းပြခိုင်းကြည့်ပါမယ်။ 

print("Hello, World!")

Output

Hello, World!

ဒီမှာ print() ဆိုတဲ့ Instruction ကို အသုံးပြုပြီး Computer ကို စာသားတစ်ခုကို Screen ပေါ်မှာ ပြခိုင်းထားတာ ဖြစ်ပါတယ်။

5. Programming မှာ ဘာတွေ လုပ်ရလဲ?

Program တစ်ခုရေးတဲ့အခါ Code ရေးရုံနဲ့ မပြီးပါဘူး။ Problem ကို နားလည်ပြီး Solution တစ်ခုကို စဉ်းစားရပါတယ်။

Problem → ဘာပြဿနာကို ဖြေရှင်းမလဲ?

Logic → ဘယ်လိုဖြေရှင်းမလဲ?

Code → Solution ကို Programming Language နဲ့ ရေးမယ်။

Test → Program က မှန်ကန်စွာ အလုပ်လုပ်လား စစ်မယ်။

ဒါကြောင့် Programming ဆိုတာ Code ရေးတာတစ်ခုတည်း မဟုတ်ပါဘူး။ Problem Solving နဲ့ Logic လည်း အရေးကြီးပါတယ်။

6. Programming နဲ့ Coding တူသလား?

Programming နဲ့ Coding ဟာ ဆက်စပ်ပေမယ့် အဓိပ္ပာယ်တစ်ထပ်တည်း မဟုတ်ပါဘူး။

Coding ဆိုတာ Programming Language အသုံးပြုပြီး Instructions တွေကို Code အဖြစ် ရေးသားခြင်းကို အဓိက ဆိုလိုပါတယ်။

Programming ကတော့ Problem ကို နားလည်ခြင်း၊ Solution စဉ်းစားခြင်း၊ Code ရေးခြင်း၊ Test လုပ်ခြင်း စတဲ့ လုပ်ငန်းစဉ်တစ်ခုလုံးကို ပိုမိုကျယ်ပြန့်စွာ ဆိုလိုပါတယ်။

📌 Key Points

  • Programming သည် Computer ကို Instructions ပေးရန် ရေးသားတဲ့ လုပ်ငန်းစဉ် ဖြစ်သည်။
  • Computer သည် ပေးထားတဲ့ Instructions များအတိုင်း လုပ်ဆောင်သည်။
  • Programming Language များကို Program ရေးသားရန် အသုံးပြုသည်။
  • Python, Java, C, C++, JavaScript တို့သည် Programming Languages များ ဖြစ်သည်။
  • Programming သည် Code ရေးခြင်းတစ်ခုတည်း မဟုတ်ဘဲ Problem Solving နှင့် Logic လည်း ပါဝင်သည်။
  • Coding သည် Programming ၏ အရေးကြီးသော အစိတ်အပိုင်းတစ်ခု ဖြစ်သည်။
