FREE LESSON 04

Operators

Programming မှာ Data တွေကို ဘယ်လိုတွက်ချက်၊ နှိုင်းယှဉ်ပြီး လုပ်ဆောင်ချက်တွေ ပြုလုပ်မလဲ?

🎯 Learning Objective

ဒီ Lesson ပြီးဆုံးတဲ့အခါ Operator ဆိုတာဘာလဲ၊ Programming မှာ Operators တွေကို ဘာကြောင့်အသုံးပြုရသလဲ၊ အသုံးများတဲ့ Operators အမျိုးအစားတွေကို ခွဲခြားနားလည်ပြီး အသုံးပြုနိုင်မှာဖြစ်ပါတယ်။

1. Operator ဆိုတာဘာလဲ?

Programming မှာ Operator ဆိုတာ Data တွေ၊ Values တွေကို တွက်ချက်ခြင်း၊ နှိုင်းယှဉ်ခြင်း၊ သတ်မှတ်ခြင်း စတဲ့ လုပ်ဆောင်ချက်တွေ ပြုလုပ်ဖို့ အသုံးပြုတဲ့ Symbol ဖြစ်ပါတယ်။

Real-life Example 💡

10 + 5 ဆိုတဲ့ Expression မှာ + က Number နှစ်ခုကို ပေါင်းဖို့ အသုံးပြုတဲ့ Operator ဖြစ်ပါတယ်။

10 နဲ့ 5 က Values တွေဖြစ်ပြီး + က Operator ဖြစ်ပါတယ်။

2. Arithmetic Operators

Arithmetic Operators တွေကို Mathematical calculations တွေ ပြုလုပ်တဲ့အခါ အသုံးပြုပါတယ်။

+ → Addition

- → Subtraction

* → Multiplication

/ → Division

% → Remainder 
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

Output

13
7
30
3.3333333333333335
1

ဒီမှာ % Operator က Division ပြီးတဲ့အခါ ကျန်တဲ့ Remainder ကို ပြန်ပေးပါတယ်။

3. % Operator ကို နားလည်ကြည့်မယ်

% Operator ကို Programming မှာ အရမ်းအသုံးများပါတယ်။ အထူးသဖြင့် Number တစ်ခုရဲ့ Even / Odd ကို စစ်တဲ့အခါ အသုံးဝင်ပါတယ်။

10 % 2 = 0

10 ကို 2 နဲ့စားတဲ့အခါ Remainder က 0 ဖြစ်တဲ့အတွက် 10 ဟာ Even Number ဖြစ်ပါတယ်။

7 % 2 = 1

7 ကို 2 နဲ့စားတဲ့အခါ Remainder က 1 ဖြစ်တဲ့အတွက် 7 ဟာ Odd Number ဖြစ်ပါတယ်။ 
number = 7

print(number % 2)

Output

1

4. Comparison Operators

Comparison Operators တွေကို Values နှစ်ခုကို နှိုင်းယှဉ်တဲ့အခါ အသုံးပြုပါတယ်။

== → Equal to

!= → Not equal to

> → Greater than

< → Less than

>= → Greater than or equal to

<= → Less than or equal to 
age = 20

print(age == 20)
print(age > 18)
print(age < 18)

Output

True
True
False

Comparison Operator တွေက အများအားဖြင့် True သို့မဟုတ် False ဆိုတဲ့ Boolean Result ကို ပြန်ပေးပါတယ်။

5. Logical Operators

Logical Operators တွေကို Conditions နှစ်ခု သို့မဟုတ် နှစ်ခုထက်ပိုတာတွေကို ပေါင်းစပ်ပြီး စစ်ဆေးတဲ့အခါ အသုံးပြုပါတယ်။

AND → Conditions အားလုံး True ဖြစ်ရမယ်

OR → Condition တစ်ခုခု True ဖြစ်ရင် ရမယ်

NOT → True / False ကို ပြောင်းပြန်လုပ်တယ် 
age = 20
has_id = True

print(age >= 18 and has_id)
print(age < 18 or has_id)

Output

True
True

6. Assignment Operators

Assignment Operator ကို Value တစ်ခုကို Variable ထဲ သတ်မှတ်ပေးတဲ့အခါ အသုံးပြုပါတယ်။

= → Value သတ်မှတ်ခြင်း

+= → ပေါင်းပြီး ပြန်သတ်မှတ်ခြင်း

-= → နုတ်ပြီး ပြန်သတ်မှတ်ခြင်း

*= → မြှောက်ပြီး ပြန်သတ်မှတ်ခြင်း

/= → စားပြီး ပြန်သတ်မှတ်ခြင်း 
score = 10

score += 5

print(score)

Output

15

7. Increment & Decrement

Programming မှာ Value တစ်ခုကို တစ်ဆင့်တိုးခြင်း၊ တစ်ဆင့်လျှော့ခြင်းတွေကို Increment / Decrement လို့ခေါ်ပါတယ်။

Increment → Value ကို တိုးခြင်း

Decrement → Value ကို လျှော့ခြင်း

Programming Language တစ်ခုနဲ့တစ်ခု Increment / Decrement ရေးသားပုံ ကွာနိုင်ပါတယ်။ 

# Python

count = 5

count += 1

print(count)

Output

6

📌 Key Points

  • Operator သည် Data သို့မဟုတ် Values များပေါ်တွင် လုပ်ဆောင်ချက်ပြုလုပ်ရန် အသုံးပြုသည်။
  • Arithmetic Operators များကို Mathematical calculations များအတွက် အသုံးပြုသည်။
  • % Operator သည် Division ပြီးနောက် Remainder ကို ပြန်ပေးသည်။
  • Comparison Operators များသည် Values များကို နှိုင်းယှဉ်ရန် အသုံးပြုသည်။
  • Comparison Result သည် အများအားဖြင့် True သို့မဟုတ် False ဖြစ်သည်။
  • Logical Operators များကို Conditions များကို ပေါင်းစပ်ရန် အသုံးပြုသည်။
  • Assignment Operators များကို Values များကို Variable ထဲ သတ်မှတ်ရန် အသုံးပြုသည်။
  • Programming Language တစ်ခုနဲ့တစ်ခု Operator ရေးသားပုံအချို့ ကွာနိုင်သည်။
