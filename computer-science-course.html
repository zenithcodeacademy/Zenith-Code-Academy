Course Overview

Understand Computer Science from the fundamentals.

This course introduces the fundamental concepts of Computer Science through programming logic, problem solving, algorithms, data representation, flowcharts, programming fundamentals, data structures, and algorithm efficiency. Students will learn not only how to write code, but also how to think systematically and design solutions before coding.

Skills and knowledge you will develop throughout the course.

12-Week Course Outline

A structured journey from Computer Science fundamentals to practical programming and problem solving.

Week Theory & Concepts Details Hands-on Labs / Learning Outcomes
1 Introduction to Computer Science What is Computer Science? Computer Science vs IT, Software vs Hardware, and the role of Computer Science in the real world. Identify hardware and software components; explore real-world Computer Science applications.
2 How Computers Work CPU, Memory, Storage, Input/Output, Operating Systems, and basic computer architecture. Trace how a simple program is processed by a computer and understand the role of each major component.
3 Number Systems & Data Representation Binary, Decimal, Hexadecimal, Bits & Bytes, and basic data representation. Binary ↔ Decimal conversions and basic storage calculations.
4 Programming Logic & Problem Solving Problem definition, Input, Process, Output, decomposition, and logical thinking. Solve everyday and programming problems using the Input → Process → Output approach.
5 Algorithms What is an algorithm? Characteristics of algorithms, pseudocode, and step-by-step problem solving. Write algorithms for simple real-world and programming problems.
6 Flowcharts Flowchart symbols, sequence, decision, repetition, and tracing logic. Create flowcharts for problems such as ATM transactions, login systems, and grading.
7 Programming Fundamentals Variables, constants, data types, operators, expressions, and input/output. Build small programs using fundamental programming concepts.
8 Control Structures Sequence, Selection, and Iteration. if/else, switch, and loops. Even/Odd, Largest Number, FizzBuzz, counting, and other logic-based programming exercises.
9 Functions & Modular Programming Functions, parameters, return values, scope, and modular program design. Create reusable functions and divide programs into manageable modules.
10 Data Structures Arrays, Lists, Strings, and basic data organization. Search, count, organize, and manipulate collections of data.
11 Algorithms & Efficiency Searching, Sorting, Algorithm Efficiency, and introduction to Big-O notation. Practice Linear Search and simple sorting techniques and compare approaches.
12 Problem Solving & Mini Project Applying Computer Science concepts to a complete problem: Analysis → Algorithm → Flowchart → Code → Testing. Build and present a small programming project using the concepts learned throughout the course.

🚀 Final Project

Apply the Computer Science concepts you have learned by analyzing a real-world problem, designing an algorithm, creating a flowchart, implementing the solution in code, and testing the final program.

Problem → Algorithm → Flowchart → Code → Test
