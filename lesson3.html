FREE LESSON 03

Data Types

Programming မှာ Data တွေကို ဘယ်လိုအမျိုးအစားခွဲခြားသတ်မှတ်မလဲ?

🎯 Learning Objective

ဒီ Lesson ပြီးဆုံးတဲ့အခါ Data Type ဆိုတာဘာလဲ၊ Data တွေကို ဘာကြောင့် အမျိုးအစားခွဲခြားရသလဲ၊ Programming မှာ အသုံးများတဲ့ Data Types တွေကို ခွဲခြားနားလည်နိုင်မှာဖြစ်ပါတယ်။

1. Data Type ဆိုတာဘာလဲ?

Programming မှာ Data Type ဆိုတာ Data တစ်ခုရဲ့ အမျိုးအစား ကို သတ်မှတ်ပေးတာဖြစ်ပါတယ်။

Real-life Example 💡

စာအုပ်တစ်အုပ်၊ ရေတစ်ခွက်နဲ့ လူတစ်ယောက်ရဲ့ အသက်ဟာ Data တွေဖြစ်ပေမယ့် အမျိုးအစားမတူကြပါဘူး။

Programming မှာလည်း Number၊ Text၊ True / False စတဲ့ Data တွေကို အမျိုးအစားခွဲခြားထားပါတယ်။

2. Data Type ကို ဘာကြောင့်သုံးတာလဲ?

Program တစ်ခုမှာ Data အမျိုးမျိုးကို ကိုင်တွယ်အသုံးပြုရပါတယ်။ Data ရဲ့ အမျိုးအစားကို သိထားမှ အဲဒီ Data ပေါ်မှာ ဘယ်လိုလုပ်ဆောင်မှုတွေ ပြုလုပ်နိုင်မလဲ ဆိုတာကို Programming Language က သတ်မှတ်နိုင်ပါတယ်။

ဥပမာ —

20 ဆိုရင် Number ဖြစ်ပြီး တွက်ချက်မှုတွေ ပြုလုပ်နိုင်ပါတယ်။

"Hello" ဆိုရင် Text ဖြစ်ပြီး စာသားအဖြစ် အသုံးပြုပါတယ်။

True / False ဆိုရင် Boolean Data ဖြစ်ပြီး အခြေအနေတစ်ခု မှန်၊ မမှန်ကို ကိုယ်စားပြုပါတယ်။

3. Common Data Types

Programming Language အများစုမှာ Data Type အမျိုးအစားများစွာရှိပါတယ်။ အခြေခံအနေနဲ့ အသုံးများတဲ့ Data Types တွေကတော့ —

Integer → ကိန်းပြည့်

Float → ဒဿမကိန်း

String → စာသား

Boolean → True / False

4. Integer

Integer ဆိုတာ ဒဿမမပါဝင်တဲ့ ကိန်းပြည့်တွေကို ဆိုလိုပါတယ်။

ဥပမာ — 10, 20, 0, -5 
age = 20

print(age)

Output

20

5. Float

Float ဆိုတာ ဒဿမကိန်းတွေကို ကိုယ်စားပြုတဲ့ Data Type ဖြစ်ပါတယ်။

ဥပမာ — 3.14, 10.5, -2.5 
price = 10.5

print(price)

Output

10.5

6. String

String ဆိုတာ စာသားတွေကို ကိုယ်စားပြုတဲ့ Data Type ဖြစ်ပါတယ်။

စာသားတွေကို Programming Language အများစုမှာ Quotes တွေအတွင်း ရေးသားလေ့ရှိပါတယ်။ 
name = "Zenith"

print(name)

Output

Zenith

7. Boolean

Boolean ဆိုတာ True ဒါမှမဟုတ် False ဆိုတဲ့ တန်ဖိုးနှစ်မျိုးထဲက တစ်ခုကိုသာ ကိုယ်စားပြုတဲ့ Data Type ဖြစ်ပါတယ်။

Boolean ကို Program တစ်ခုမှာ အခြေအနေတစ်ခု မှန်၊ မမှန် စစ်ဆေးတဲ့အခါ အသုံးများပါတယ်။ 
is_student = True

print(is_student)

Output

True

8. Programming Example

Data အမျိုးအစားတွေကို Variable တွေနဲ့ တွဲပြီး အသုံးပြုနိုင်ပါတယ်။ 

age = 20

height = 5.8
name = "Zenith"
is_student = True

print(age)
print(height)
print(name)
print(is_student)

Output

20

5.8
Zenith
True

ဒီ Program မှာ Variable တစ်ခုချင်းစီထဲမှာ သိမ်းထားတဲ့ Data တွေဟာ အမျိုးအစားမတူကြတာကို တွေ့နိုင်ပါတယ်။

📌 Key Points

  • Data Type သည် Data တစ်ခု၏ အမျိုးအစားကို သတ်မှတ်ပေးသည်။
  • Programming မှာ Data အမျိုးအစားအမျိုးမျိုး ရှိသည်။
  • Integer သည် ကိန်းပြည့်များကို ကိုယ်စားပြုသည်။
  • Float သည် ဒဿမကိန်းများကို ကိုယ်စားပြုသည်။
  • String သည် စာသားများကို ကိုယ်စားပြုသည်။
  • Boolean သည် True သို့မဟုတ် False ကို ကိုယ်စားပြုသည်။
  • Programming Language တစ်ခုနဲ့တစ်ခု Data Type များနှင့် ရေးသားပုံ ကွာနိုင်သည်။

📝 Mini Practice

အောက်ပါ Data တွေရဲ့ Data Type ကို ခွဲခြားကြည့်ပါ။

2. 3.14

3. "Hello World"
